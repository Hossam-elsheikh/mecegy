# Middle East Consultants (MEC) Official Website

## Overview
This repository contains the official website for **Middle East Consultants (MEC)**, a premier engineering consultancy firm with over 24 years of experience delivering exceptional architectural and engineering solutions across the Middle East.

Built with **Next.js**, **React**, and **Tailwind CSS**, this modern web application serves as the digital front door for MEC, highlighting their expertise, portfolio, and commitment to quality ("Accuracy to Build").

## Key Features

- **Comprehensive Services Portfolio:** Details MEC's core offerings including Architecture and Design, Project Management, and Construction Management & Supervision.
- **Project Showcase:** A dynamic portfolio highlighting significant milestones across various sectors:
  - **Educational:** Merit University, Assiut University facilities.
  - **Medical:** Lifer Medical Park, 3i Pharma logistics hub.
  - **Residential & Commercial:** Crown Key, Heraa Projects.
  - **Infrastructure:** Manqabad Overpass in Assiut.
- **Client Testimonials:** Insights and reviews from prominent clients and partners.
- **Engineering Blog & News:** Updates on company achievements, such as acquiring ISO 9001 certification, and participation in engineering employment fairs.
- **Careers Portal:** A "Join Us" section for aspiring civil, architectural, electrical, and mechanical engineers to submit their applications.
- **Company Branches:** Information for MEC's main headquarters in Sohag, and branches in Assiut and Giza.

## Technology Stack

- **Framework:** Next.js (App Router)
- **Library:** React
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript

## Getting Started

To run the development server locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
